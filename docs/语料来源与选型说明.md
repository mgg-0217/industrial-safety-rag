# 语料来源与选型说明 · 工业设备维修与安全规程问答 RAG

> 结论先行：**选了"危化品/特种设备安全规程 + 事故调查报告 + 国家与行业标准导则"这个组合**。
> 理由：这是国内公开度最高、结构最完整、且天然带位号/条款号/数值/危险源标签的一类工业文档，
> 与目标场景的元数据 schema 完全对得上，不需要靠编造数据来补。

## 一、为什么公开数据可行，而且比想象中好

你原本担心"行业类型选哪类数据好找"。实测下来，**真正难找的不是安全规程，而是厂商设备手册**：

| 尝试的源 | 结果 | 结论 |
|---|---|---|
| 施耐德中国（ATV320 编程手册，中文，23MB，含完整故障码表） | `download.se.com` 301→404，403 防盗链 | ❌ 境外/防盗链 |
| 西门子 support（109741502） | 403 | ❌ 反爬 |
| 汇川 inovance.com | SPA 空壳（11KB），无 PDF 直链 | ❌ |
| 英威腾 invt.com.cn | Ajax 渲染，页面里无直链 | ❌ |
| 中国政府采购网 ccgp.gov.cn | OSS 直链返回错误页；招标文件本体需 CA 报名 | ❌ 不划算 |
| **中国政府网站（应急管理部/省应急厅/市政府/市监局）** | **直连可下，HTML正文+PDF附件均有** | ✅ **主力通道** |
| 应急管理部官网 mem.gov.cn PDF 附件 | 直链 2.3MB 下载成功 | ✅ 最佳单文件源 |

**结论**：厂商手册拿不到（版权+防盗链），但政府公开文件恰好覆盖了场景里**更严格的那一半**——
安全规程、事故调查、设备完好性管理导则。而设备维修侧的真实数据，
由**事故调查报告**和**设备完好性管理导则**补足（下面第二节讲为什么够用）。

## 二、选型逻辑：为什么是这三类文档的组合

目标场景要回答两类问题：

**A. 安全规程类**（"动火作业能不能做""受限空间怎么进"）
→ 需要：条款编号、文件号、生效日期、危险源标签、明确的责任主体
→ 来自：政府公开的**制度/规程/应急预案**，天然带"第X条"和"XX办发〔2025〕1号"

**B. 设备维修类**（"19-V-4215 罐压力异常怎么处置""设计压力是多少"）
→ 需要：设备位号、设计参数（温度/压力/容积）、故障时序、处置动作
→ 来自：**事故调查报告**——这是目前唯一能公开拿到、且**带完整设备位号和参数**的工业文档

三份核心样本说明 B 类为什么够用：

### 1. 泉州中化学天辰"12·20"泄漏爆炸事故调查报告（12.5K 字）
真实工业数据的密度极高：

```
设备名称：粗产品缓冲罐，设备编号：19—V—4215，该设备为第二类压力容器
设备容积 13.1 m³，操作压力 0.2 MPa，设计压力 0.35 MPa/FV（全真空）
操作温度 54℃，设计温度 90℃，介质为环氧丙烷和甲醇
管道 MP—41009—200—S1B—H1：Φ219.1×4mm，设计压力 0.5 MPa，工作压力 0.3 MPa
阀门 1910—PV—42151：平衡密封型套筒调节阀，口径 DN150/DN125，气开阀 FC
耐压试验压力 0.44 MPa，泄漏试验压力 0.35 MPa
```
还带完整故障时序：`6:27 压力从 49.8KPa 升高 → 7:03 超压 100KPa（正常 35~50KPa）
→ SIS 联锁切断再沸器 → 7:46 手动开大调节阀至 18% → 8:07 压力涨到 0.4MPa（超量程）
→ 8:09 泄漏 → 爆炸着火`

→ 一次覆盖：**位号抽取、参数保真、故障树问答、跨文档推理**四类测试。

### 2. AQ/T 3034—2022《化工过程安全管理导则》（59 页 / 41 张表 / 5.7 万字）
> 4.10 设备完好性管理：企业应建立设备设施操作规程和检维修规程、巡回检查管理制度，
> 明确润滑/盘车/定期切换等日常维护，实行设备与备品备件（含安全附件）台账管理

→ 这是**设备维修轨的规范依据**，行业标准级，可直接支撑"检维修规程要包含什么"这类问题。

### 3. 榆林市动火和受限空间作业安全管理制度（2025 版 + 2023 版）
> 第十九条：本制度自印发之日起施行。原《...》（榆政办发〔2023〕26号）同时废止。

→ **两版都在库里，且新版明示废止旧版**。这天然构成了版本治理的黄金测试集：
- 该问 2023 版时应召回 2023 版
- 默认检索应过滤掉已废止版本
- 召回到过期版本 = 直接判错

## 三、数据类型覆盖矩阵（对照你的需求清单）

| 你的需求 | 覆盖情况 | 真实样本 |
|---|---|---|
| Word | ⚠️ 缺 | 公开政府源几乎只有 HTML/PDF。**需从你的内部手册补** |
| 文本型 PDF | ✅ 充分 | mem 导则(55p)、AQ/T3034(59p)、高青(7p) |
| **图片型 PDF** | ✅ 有真实样本 | `yuncheng_paichabiao.pdf` —— 实测**无文本层**（0 字符 / 2 页纯图），是货真价实的扫描件，用来跑 OCR 链路 |

| **QA 形式的 Excel / CSV** | ⚠️ 待造 | 用真实文档抽条款自动生成 QA 对，导出 CSV（下一步） |
| 表格密集 | ✅ 充分 | 导则 41 张表 + 排查导则 35 张表 + 作业票 2 张表 |
| 版本并存 | ✅ | 榆林 2025 版 / 2023 版（含废止声明） |

## 四、下载与抽取通道（可复现）

```bash
cd D:/ccworkplace/工业维修安全规程RAG

# 1) HTML 正文 -> Markdown（带 front-matter 元数据）
python tools/html_to_md.py data/raw data/md

# 2) PDF -> Markdown（保留页码锚点 <!-- page:N --> 与表格结构）
python tools/pdf_to_md.py data/raw data/md

# 3) PDF 探针：判定文本型 / 扫描件 / 表格数
python tools/pdf_probe.py data/raw data/probe_report.json

# 4) 生成语料清单与 manifest.json
python tools/build_manifest.py
```

抽取器做了两件针对政府页面的适配：
- **标签配对提取**（`extract_balanced`）—— 政府页面普遍用嵌套 `<div>`，非贪婪正则会在第一层 `</div>` 截断（实测海阳页 139KB 只出 466 字的根因）
- **正文区间兜底** —— 容器提取 <1200 字时，回退到全文清洗 + 标题/尾部标记定位

## 五、缺口与补齐方案（诚实清单）

| 缺口 | 影响 | 补齐方式 |
|---|---|---|
| **Word 文档** | 你的实际语料主力是 Word(.docx)，公开源几乎没有 | **用你的内部维修手册替换**，或用 `python-docx` 造一份格式等价的样例（≤10 页） |
| **厂商设备手册**（参数表/故障码/拆装步骤） | 设备维修侧缺少"操作型"文档（现在是"事故复盘型"） | 用你的内部手册；或补 **CNIPA 专利公开文本**（设备维修方法专利，全文公开合法） |
| **QA 形式的 Excel/CSV** | 第 6 种切分策略（QA-pair）无验证语料 | 从真实条款自动抽 QA 对导出 CSV（下一步做） |
| 3 份 HTML 正文不全 | 安徽/淮安/海阳 | 安徽、海阳页面正文是图片版，需 OCR；淮安 URL 失效，已由 mem 官方 PDF 覆盖 |

**不打算用编造数据填空**——宁可清单里如实标 `extract_quality: partial/failed`，
也不往库里塞假文档污染评测集。

## 六、合规说明

- 全部语料来自**中国政府网站公开文件**（应急管理部 / 省应急管理厅 / 市政府 / 市市场监督管理局），
  属可公开引用的政府公开信息；
- 仅用于内部 RAG 研发、测试与评测，**不对外再分发**，不在对外产品中直接呈现原文全文；
- 原始文件的来源 URL、发布单位、文号、生效日期均已记录在 `data/manifest.json`，
  便于回答时做条款级溯源与合规复核；
- 厂商手册因版权与防盗链不可得，本轮**未使用任何受版权保护的厂商文档**。
