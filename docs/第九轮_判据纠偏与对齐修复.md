## 1. 🔴 判据本身的错：**量纲检查既误报又漏报**

原判据是"扫描题干里出现了哪些**单位字面**"，两种错法都出现了：

| 现象 | 例子 | 原判据 |
|---|---|---|
| **误报** | 题干"氩气**浓度**达到什么程度时，可在**数分钟内**导致窒息" —— 问的是浓度（%），"数分钟内"只是时限条件 | 看到"分钟"→ 报"量纲对不上" ❌ |
| **漏判** | 题干问"氮气吹扫**压力**限值"，锚点却含 `71 ℃`/`85 ℃` —— 题干里没有任何单位字面 | 不报 ❌（真该报） |

**修法**：改成**按量纲族**判（`src/units.py`）——
题干的**量名**（浓度/时间/压力/长度/体积/质量/温度/功率…）→ 题干族**集合**；
锚点的**单位** → 锚点族集合；只有"锚点族 ∩ 题干族 = ∅"且两边都非空时才报。
题干含多个量名时（浓度 + 时间），命中任一即通过。

🔴 **族定义自己也写错了两处**（实测才发现）：
* **"体积分数"是浓度不是体积** —— 题干"甲烷达到什么**体积分数**范围"、锚点 `25 %`/`30 %`
  → 判成体积族会**误报**；
* **"储量"是质量不是体积** —— 题干"其**储量**满足什么条件"、锚点 `5 t`（吨）
  → 同样误报。

→ 族定义放 `src/` 而不是散在工具里：**质检与锚点修复必须用同一份判定**，
两处各写一套必然打架（K-74 / K-83 的教训）。

## 2. 🔴 `best_span` 的**坐标 bug**（影响所有对齐）

```python
cand = seg_f[block.a:block.a + block.size]   # ❌
```

`block.a` 是**kp 里的**位置，`block.b` 才是**原文段里的**位置 ——
原代码拿 kp 的坐标去切原文段，**切出来的根本不是公共片段**。

实测（修前）：

| kp | 真实公共块 | 切出来的（错） |
|---|---|---|
| 「特种设备事故应急救援工作坚持…」 | **4 字**（"特种设备"） | 「范围锅炉,压力容器(含气瓶)…」**34 字** |

→ 修成 `seg_f[block.b:block.b + block.size]`。

🔴 **影响面**：`best_span` 是 `fix_key_points.py` / `relink_test_set.py` /
`align_key_point` 的共同底层 → **凡是"对齐"产出的片段都可能是错的**。
⚠️ 题集里 `key_point_source = "aligned_to_source"` 的 **84 条**是旧代码的产物，
理论上该重跑（本次未做，已列入下一步）。

## 3. kp 对齐回原文：片段级 + 句级两道

`tools/fix_fact_keypoints.py`：
* **片段级**：`best_span` 的公共块 ≥ **40%** 且 ≥ 8 字
  （不能用 `align_key_point` 的默认门槛 4 字 —— 它是为**切片**设计的，
  在整篇文档上会**乱抓**：「检查装备。结合有限空间辨识情况…」被对成 **「局文件高」**）；
* **句级**：按句切分原文，用**所有公共块之和**（而非最长块）算覆盖率，
  ≥50% 时取**整句**（原文形态）。

🔴 **为什么句级要用"总和"而不是"最长块"**：模型改写往往**多点开花**——
原文「…贯彻"统一领导、分级管理，条块结合、以块为主"以及单位自救和社会救援相结合的原则；」
kp 写成「…贯彻政府统一领导，分级管理、条块结合、条块为主、单位自救和社会救援相结合的原则。」
最长公共块只有「统一领导,分级管理,条块结合,」（0.38），
但公共块**总和**覆盖了大半个 kp → 按总和判才是"这题考的是这段"的正确语义。

实测修好 2 条 kp（都是 `t_fc5c3dddf20b`）。

## 4. 单位折叠的**顺序坑**

```python
# 修前：先 match_norm（去空格）再 fold_unit
# 修后：先 fold_unit（空格还在）再归一
```

去空格之后，相邻的**选项标签会粘连**：
`"A. 5.5MPa B. 15MPa"` → `"a.5.5mpab.15mpa"` → `"15mpa"` 后面紧跟 `"b"`
→ 负向断言 `(?![a-z0-9])` 失败 → **折不掉** →
锚点 `"15 MPa"`（→`"15兆帕"`）与答案（→`"15mpa"`）对不上。

→ `fold_unit` 的规则改成 `(?<=\d)\s*unit(?![a-z0-9])`（**数字与单位之间允许空格**），
且**必须在去空格之前折**。

🔴 **对已发布数字的影响**：两个批次（主集 / fixed+top5）重算后**数字不变**
（组 1 = 组 2）—— 受影响的题恰好没进这两批；但**溯源判据变准了**
（`"15 MPa"` 现在能在原文里找到）。
