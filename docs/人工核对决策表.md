## 三、口径与代码改动

1. **`src/units.py`：`存量` → 体积族**（原在质量族）。
   * 依据：题干「硝酸铵溶液罐区…单个罐区**存量**最高不超1000m3」（m³ 体积）；
   * 已核：题集里含「存量」的只有这一条；「储量 5 t」是另一条（`t_a2fc6d8c56f8`），仍留质量族；
   * 判据：`dimension_conflict` 修正前报「题干问质量、锚点体积」，修正后不报。
2. **`key_point_source = manual_fix`**（9 条统一改写）。
   后果：`realign_keypoints.py`（只动 `aligned_to_source`）与 `refine_key_points_llm.py` 不会把这批 kp 覆盖回去。
3. **首个范围锚点** `35～50KPa`：本地验证评分端 `numeric_hits` 命中 1/1
   （`normalize_number` 把 `35～50KPa` 折成 `35-50千帕`，答案侧同形态即可）。
4. 本轮**没有**新增踩坑编号（K-90「量名→族的映射自己也会写错」已覆盖「存量」这一形态，此处是同类再犯）。
5. **`check_test_set.py::mask_ids()`（2026-11-09）**：查「题干泄漏数值」前，先把**位号/型号**
   （字母+数字混排、长度 ≥6）掩码。修掉的假阳性：`t_261e74c75ba7` 的锚点「4 mm」被判泄漏，
   其实「4」在 `MP—41009—200—S1B—H1` 里；短串（如 `0.1MW`）不掩码，仍按泄漏报。
